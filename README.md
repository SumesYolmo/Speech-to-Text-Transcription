# Speech-to-Text Transcription

A simple Python application that converts speech into text using the SpeechRecognition library.

## Features

- Convert live microphone speech to text
- Convert WAV audio files to text
- Save transcription to a text file
- Simple menu-driven interface
- Easy to use

## Technologies Used

- Python 3
- SpeechRecognition
- PyAudio

## Installation

Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/Speech-to-Text-Transcription.git
```

Go into the project folder

```bash
cd Speech-to-Text-Transcription
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run the program

```bash
python app.py
```
